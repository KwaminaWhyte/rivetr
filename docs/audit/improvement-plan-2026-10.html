UI / UX

Most items come from the June UX audit and are still open. Items tagged "new" are from today. The uncommitted edits to apps/$id/_layout.tsx and the project tabs may already touch some of these; re-check before starting.

Security

All three Criticals from June are fixed or mostly fixed (MCP auth, 2FA bypass, IDOR middleware), as are webhook fail-closed, remote path injection, and white-label authz. What is left is the hardening tail. "Verified open today" means I confirmed it in the code.

Competitive angle: Coolify disclosed 11 critical CVEs in January 2026 and Dokploy shipped a v0.30.4 fix for git-provider secrets leaking to non-owner org members. A published threat model, signed releases and an SBOM would turn the audit work into a selling point.

Performance

The ~30MB idle pitch is the product. The leaks that threaten it are all unbounded growth (logs, tables, channels) and per-request or per-container serial work.

Pending features

Roadmap says 599/599, but several things are still genuinely open, and docs/planning/tasks.md has about 40 unticked boxes that look stale (features that shipped, per the changelog). Reconcile that file so it stops lying.

Parked on purpose: the host resource safety-net (512MB default cap, label-scoped prune) is on hold per your saved note until the new droplet. Changelog 0.10.23 already shipped part of it (default limits, log rotation, critical-disk reclaim); only the remaining pieces are waiting.

What the leaders shipped recently (the bar to meet)

Dokploy v0.28 to v0.30 (2026)

AI log and build error analysis, MCP server and CLI with full API coverage, shared git providers, LibSQL, non-root multi-server, Docker networks UI (v0.30.0), SSO and Patches (v0.28), Apache 2.0 license.

Rivetr: has AI diagnose, MCP (9 tools), LibSQL, patches. Missing: Docker networks UI, full-coverage CLI.

Coolify v4.1 to v4.3 (2026)

Railpack beta, structured audit logging, instance-level MCP (read-only), scheduled volume backups with retention (v4.2.0). v5 is in development with multi-server scalability as the focus; no feature list or date found.

Rivetr: ahead on Railpack, audit, MCP. Check scheduled volume backups with retention.

Where to be careful

  • Do not chase HTTP/3, Kubernetes, or Hetzner provisioning. Neither leader has a strong lead there and the cost is high.
  • SAML 2.0 is the one enterprise ask that is real, but build it only when a paying or pilot user requests it.
  • Template count (about 250 vs 388-400+) is a vanity gap. Quality and one-click reliability matter more than count.
